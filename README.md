# Syntecxhub_Maze_Solver_Astar

Project 1 submission for Syntecxhub Internship - **Maze Solver using A* Search**.

## Project Overview
This project implements the **A* Search Algorithm** to find the shortest path in a grid-based maze. It utilizes the Python `pyamaze` library to visually render the maze, handle walls, and trace the optimal path from the start point to the goal.

## Features
- Grid representation with customizable rows and columns.
- Implementation of A* Search using **Manhattan Distance** as a heuristic function.
- Visual step-by-step agent animation and path tracing.
